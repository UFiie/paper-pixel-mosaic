# paper-pixel-mosaic

A prompt-based image generation skill for creating 3:4 vertical artistic posters in a "photography × watercolor square mosaic collage" style.

## Core Features
- Upper half preserves the original photo
- Lower half reconstructs the subject with watercolor paper square tiles
- Bright, fresh, handcrafted paper texture
- Optional handwritten side caption

## Main File
- `SKILL.md`: the full skill specification

## Usage
Use this skill with an input image and optionally provide:
- a short caption
- whether to auto-generate an English phrase
- whether to preserve visible key text in the original object
